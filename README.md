# Mohammed Asmare — Portfolio

Modern, responsive, enterprise-grade personal portfolio website for **Mohammed Asmare**, **Full Stack Developer & QA Engineer** based in Addis Ababa, Ethiopia.

## 🚀 Live Demo & Portfolio Highlights

- **Hero & Interactive Terminal**: Live `$ mohammed --status` terminal simulator, API Flow topology visualizer, and syntax-highlighted Java Spring Boot controller code inspector.
- **Experience Timeline**: Highlights specialist integration work at **Safaricom Ethiopia** and **Exceed**, including 20+ commercial bank integrations and legacy TIBCO-to-Spring Boot modernization.
- **Technical Skills Arsenal**: Searchable and filterable grid across Programming, Frontend, Backend, Database, QA & Testing, DevOps, Enterprise Integration, and Monitoring.
- **Enterprise Case Studies**: Deep architecture breakdown modals for API microservices, middleware modernization, CI/CD Kubernetes deployments, and System Integration Testing (SIT) frameworks.
- **Curriculum Vitae Modal**: Interactive printable/saveable resume viewer.
- **Dark/Light Mode**: Smooth theme toggling with `localStorage` persistence.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Framer Motion, Lucide React
- **Build Tool**: Vite
- **Methodology**: Component-driven architecture, responsive design, dark/light theme switching

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/MohammedAsmare/my-portfolio.git
cd my-portfolio
npm install
```

Start local dev server:

```bash
npm run dev
```

Build production bundle:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
